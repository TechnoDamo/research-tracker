# Replace with the research topic

## Objective

Describe the research decision or understanding this archive should support.

## Core research question

Write the agreed question.

## Include

List meaningful methods, evidence, updates, and release types within scope.

## Exclude

List the boundaries and common false positives.

## Search vocabulary

List terms, synonyms, and adjacent concepts; these are starting points for broader discovery.

## Relevance levels

- **High:** Directly answers the question.
- **Medium:** Adjacent work with an explicit useful connection.
- **Low:** Peripheral evidence worth retaining for a concrete reason.

## Eligible release types

Record the agreed source and release types without confusing publication status with evidence strength.
