### zero-order-training-2026-10-06-zocheck — ZOCheck: CPU-Shadow Checkpointing for Zeroth-Order LLM Fine-Tuning

- **Authors:** Minqiu Sun, Xin Huang, Luanzheng Guo, Nathan R. Tallent, Kento Sato, Dong Dai.
- **Publication/release date:** 2026-09-23.
- **Source / venue:** arXiv (`arxiv`); arXiv record notes acceptance to SC26, not independently checked against proceedings in this session.
- **Publication type:** preprint.
- **Canonical URL:** https://arxiv.org/abs/2609.27189
- **Importance:** 3/5.
- **Relevance:** high.
- **Evidential maturity:** 3/5.
- **Contribution:** ZOCheck uses a CPU shadow process to replay compact update logs and save recovery images without blocking GPU training. Its authors report up to 219.7× lower checkpoint overhead, 1.55× lower average recovery latency, and up to 21.3× lower wasted time over evaluated failure rates relative to asynchronous full-state checkpointing.
- **Why it matters:** ZO training has a distinctive replayable update state; fault tolerance could make long, low-memory runs more practical.
- **Evidence and source quality:** Original systems preprint with quantitative comparisons and an [author-linked code repository](https://github.com/DIR-LAB/ZOCheck). The acceptance statement is from arXiv metadata, while the performance numbers remain first-party experimental claims.
- **Major limitations:** Gains depend on the failure-rate and baseline settings studied; this addresses recovery cost, not the convergence or quality gap between ZO and backpropagation.
- **Code / project URL:** https://github.com/DIR-LAB/ZOCheck
- **Status / update:** New preprint, catalogued retrospectively on 2026-10-06.

### zero-order-training-2026-10-06-termezo — TerMeZO: Ternary Sparse Zeroth-Order Optimization for Fine-tuning BitNet Models at the Edge

- **Authors:** Houssem Sifaou, Prabodh Katti, Bipin Rajendran, Osvaldo Simeone.
- **Publication/release date:** 2026-09-27.
- **Source / venue:** arXiv (`arxiv`); preprint.
- **Publication type:** preprint.
- **Canonical URL:** https://arxiv.org/abs/2609.33548
- **Importance:** 3/5.
- **Relevance:** high.
- **Evidential maturity:** 3/5.
- **Contribution:** TerMeZO selects a sparse set of latent BitNet weights for MeZO-style updates using ternary-quantizer geometry rather than first-order gradients. The authors report matching or exceeding full-parameter MeZO while reducing fine-tuning memory on 1B–3B parameter BitNet models across several task types.
- **Why it matters:** It addresses a case where nominally inference-memory ZO tuning still needs full-precision latent weights, weakening the memory advantage.
- **Evidence and source quality:** Original preprint with a convergence analysis and first-party model experiments. The abstract states the comparison but does not provide enough detail by itself to judge all memory and compute trade-offs.
- **Major limitations:** Evidence is specific to ternary BitNet models at 1B–3B scale; applicability to conventional dense transformers or pretraining is unshown here.
- **Code / project URL:** None verified.
- **Status / update:** New preprint, catalogued retrospectively on 2026-10-06.
